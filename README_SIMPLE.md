# 業務用SNSシステム かんたん利用ガイド

本システムは、外部サーバーへの設定やデータベース契約が一切不要な、
**ブラウザだけで完結して動く軽量・安全な業務用SNS** です。

---

## 1. 使い方（かんたん3ステップ）

### ステップ1: システムの起動
```bash
npm install
npm run dev
```
起動後、ブラウザで `http://localhost:3000` を開きます。

### ステップ2: タイムラインで投稿・共有
- メッセージ入力欄にテキストを入力して「投稿する」を押します。
- 📎「ファイル添付」から画像やPDFなどの資料を最大4枚まで添付できます。
- 気に入った投稿には 👍「いいね！」を押してリアクションできます。

### ステップ3: ユーザー切り替え（デモ・検証）
- 画面上部の **「⚙️ ユーザー切り替えシミュレーター」** を開くと、管理者（佐藤）、一般ユーザー（山田）、各種メンバーへワンクリックで切り替えて画面を確認できます。

---

## 2. 便利な機能

### 💬 トークグループの作成・参加
- 「💬 トークグループ管理」から、プロジェクト別や部署別のグループを作成できます。
- 「🔑 合言葉で参加」から合言葉（招待コード）を入力すると、対象グループへ自動参加できます。

### 📥 データのバックアップと復元
- 画面上部の **「📥 バックアップ」** を押すと、全投稿・グループ情報が1つのJSONファイルとしてパソコンに保存されます。
- **「📤 復元」** から保存したJSONファイルを選択すれば、いつでも以前の状態に戻せます。

### 🛡️ 管理ダッシュボード (`/admin`)
- 管理者ユーザーでログイン時、画面右上の「🛡️ 管理画面」からメンバーの権限変更や新しい合言葉の発行が行えます（初期パスワード: `admin`）。
