# AI共同設定マニュアル (AI_SETUP_GUIDE.md)

本システムは、Next.jsとSupabaseを用いて構築されたコミュニティ用SNSです。
※ `README.md` はアプリの概要・機能説明用であり、本書 `AI_SETUP_GUIDE.md` はセットアップ作業専用のガイドです。

自身で環境を構築する場合は、以下の手順とAI用プロンプトを活用し、ChatGPTやClaudeなどのAIアシスタントにナビゲートを受けながら進めてください。

---

## 1. 配布ファイル一覧

セットアップを始める前に、以下のファイルが手元にあるか確認してください。

* `README.md` : アプリの概要と要件定義
* `AI_SETUP_GUIDE.md` : 本ドキュメント（セットアップ手順とAIプロンプト）
* `schema.sql` : Supabaseのデータベース構成とRLS（セキュリティ）定義ファイル

## 2. 動作確認環境

本ガイドは以下の環境で動作確認を行っています。

* OS：Windows 10
* Node.js：20 LTS
* Next.js, Supabase, Vercel

> ※ macOSやWindows 11等でも同様に動作する可能性がありますが、本ガイドでは検証していません。

## 3. 事前準備

セットアップ開始前に以下の準備・アカウント作成が必要です。

* **GitHubアカウント** : ソースコードの管理とVercel連携用 (<https://github.com/>)
* **Supabaseアカウント** : データベースおよびストレージ用 (<https://supabase.com/>)
* **Vercelアカウント** : アプリケーションのデプロイ用 (<https://vercel.com/>)
* **Node.js** : 推奨：Node.js 20 LTS (<https://nodejs.org/>)
* **Git** : ローカル環境でのバージョン管理とリポジトリ取得用 (<https://git-scm.com/>)

> **💡 ヒント：事前準備でつまずきそうな方へ**
> アカウントの作り方やインストール方法が分からない場合は、この下の「プロンプト0」をAIに投げてサポートを受けてください。

## 4. よくあるトラブル集 (FAQ)

初心者がつまずきやすいポイントと解決策です。AIに質問する前のチェックリストとしてご活用ください。

### Q1: Storageへ画像をアップロードしようとすると 403 (Forbidden) エラーになる

**原因:** Supabase Storage の RLS (Row Level Security) ポリシーが
正しく設定されていないか、バケットが Private になっています。

**対策:**

* `sns-media` バケットの設定が「Public」になっているか確認してください。
* `schema.sql` に記載されている Storage 用の RLS（`storage.objects` への INSERT/SELECT 許可設定）が実行されているか確認してください。

### Q2: 画面が真っ白になる、または API エラーが頻発する

**原因:** 環境変数 (`.env.local` や Vercel の Environment Variables) の設定ミス、または反映漏れです。

**対策:**

* `NEXT_PUBLIC_` プレフィックスがついているキー (`URL` と `ANON_KEY`) が正しいか確認してください。
* Vercel上で環境変数を追加した場合は、再度 **Redeploy** を行わないとアプリに反映されません。

### Q3: Vercelのビルド中にエラー (Build Error) が発生する

**原因:** TypeScriptの型エラー、未使用変数の存在、または `package.json` の不整合です。

**対策:**

* エラーログの中に `Type error:` や `Lint error:` という記述があれば、ローカル環境で `npm run build` を実行して原因を特定し、コードを修正してから再度GitHubにプッシュしてください。

### Q4: Supabaseへ接続できない（データが表示されない）

**原因:** URLまたはキーが間違っているか、データベースのRLSによってアクセスがブロックされています。

**対策:**

* SupabaseのURLとキーの前後に余計な空白スペースが入っていないか確認してください。
* ログインしていないユーザーにはデータを見せないRLSが組まれている場合、アプリ上で正しくユーザーとして認識されているか（クッキー等が有効か）を確認してください。
